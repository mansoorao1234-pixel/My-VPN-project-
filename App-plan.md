# AFAQ VPN

## Project Goal
Create a secure VPN for Android,
iPhone, Windows, and macOS.

## Features
- Connect and disconnect
- Secure VPN tunnel
- Server selection
- Connection status
- Free advertising-supported plan
- Optional premium subscription

## Development Plan
1. Build Android app
2. Integrate WireGuard
3. Connect to a real VPN server
4. Test security and performance
5. Add advertising after testing
6. Expand to other platforms
